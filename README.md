## 📖 这是什么？

本项目是一份开源的 **AIGC / LLM / AI Agent 面试与成长知识库**，把 AIGC 方向零散的知识点整理成体系化、问答式的文档，帮你在面试前快速建立全局认知、查漏补缺，并**建立穿越技术周期的学习力与判断力**。

- 🧭 **本质优先**：不只告诉你 AI 技术是什么，更告诉你**哪些技术值得长期投入、为什么值得投入**，以及如何把握对 AI 技术的本质判断与跨周期学习能力。
- 🎯 **面试导向**：每篇文章都附「高频追问」，模拟面试官的连环追问；配套**分岗真题集**（算法 / 开发 / Agent）。
- 🏆 **双主线覆盖**：算法岗（AIGC / LLM / Agent / 传统深度学习 / 具身智能）与开发岗（语言 / 前后端 / AI 应用开发）一站式覆盖。
- 🆓 **完全免费 & 开源**：内容持续更新，欢迎一起完善。
- 🌏 **中文友好**：面向中文读者，兼顾通用受众与工程转型视角。

> 适合：准备 AIGC / LLM / AI Agent 算法、AI 应用开发、AI 工程等岗位面试的同学，以及想系统建立 AI 认知的开发者与求职者。

## 🧭 本项目的不同之处（必读）

市面上的面试资料大多止步于「八股文」——背下来，在面试官连环追问下容易崩塌，更关键的是**技术迭代太快，今天背的三年后可能一文不值**。

本项目与众不同的地方：

- **不仅告诉你技术是什么，更告诉你哪些 AI 技术与认知值得长期投入、为什么值得投入。**
- **教你对 AI 技术做「本质判断」与「跨周期学习能力」，并据此做出正确的职业生涯决策。**
- 我们追踪 AI 技术发展，但**不是所有 AI 技术都具备跨周期价值**。真正进入核心内容的，是经过**工业界、学术界、竞赛界、投资界、应用界**持续评估与检验的。

> 💡 别的资料教你「如何通过一次面试」，本项目教你「如何在 AI 这个十年赛道上持续成长、不惧技术更替」。

## 🚀 本地运行（VitePress 文档站）

需要 Node.js 18+。

```bash
npm install        # 安装依赖
npm run dev        # 本地开发，默认 http://localhost:5173
npm run build      # 构建静态站点，输出到 docs/.vitepress/dist
npm run preview    # 预览构建产物
```

## ☁️ 部署到 GitHub Pages（获得在线阅读链接）

本仓库已内置 GitHub Actions 工作流（`.github/workflows/deploy.yml`），推送到 `master` 分支会自动构建并部署（也兼容 `main`）。

1. 把 `Alexander-blue` 替换为你的 GitHub 用户名（README 顶部徽标、链接、config 中的 socialLinks 均含占位符）。
2. 仓库 **Settings → Pages**，把 **Source** 设为 **GitHub Actions**。
3. 推送到 `master`，Actions 自动构建发布。
4. 站点地址：`https://Alexander-blue.github.io/AIGC-Interview-Book/`。

> `docs/.vitepress/config.mts` 的 `base` 已设为 `/AIGC-Interview-Book/`，与仓库名一致。若改了仓库名或用自定义域名/根路径部署，请相应修改 `base`。
