# 🚗 02 · 自动驾驶（Autonomous Driving）

> 最早大规模落地的「具身/机器人」系统之一。算法岗中岗位稳定、工程深、数据闭环要求高。

---

## 一、系统分层
```
感知(Perception) → 预测(Prediction) → 规划(Planning) → 控制(Control)
```
- **感知**：检测（车辆/行人）、分割、车道线、BEV（鸟瞰图）感知、多传感器融合（相机/LiDAR/Radar）
- **预测**：行人与车辆轨迹预测
- **规划**：路径与行为决策（规则 / RL / 学习）
- **控制**：转向/加速/制动执行

## 二、两条技术路线
- **模块化（传统）**：各模块独立优化，可解释、易调试，但模块误差累积。
- **端到端（End-to-End）**：感知→控制直接学（输入传感器，输出控制），代表 UniAD、Tesla 路线。潜力大但可解释/安全验证难。

## 三、数据闭环（关键竞争壁垒）
- 采集 → 自动标注 → 挖掘难例（长尾场景）→ 训练 → 影子模式验证 → OTA 迭代
- 长尾 corner case（罕见场景）是落地的核心难点

## 四、大模型赋能
- 用 LLM/VLM 做「场景理解」「自然语言交互」「仿真生成」
- 世界模型用于仿真与预测

## 五、高频追问
**Q1：端到端自动驾驶的利弊？**
> 利：信息无损传递、潜力上限高；弊：可解释差、安全难验证、调试难、数据需求大。传统模块化更可控，当前量产多用混合。

**Q2：自动驾驶最大的技术难点？**
> 长尾 corner case（罕见危险场景）的数据与处理能力；感知在恶劣天气/遮挡下的鲁棒性；规划在复杂交互中的决策安全。
