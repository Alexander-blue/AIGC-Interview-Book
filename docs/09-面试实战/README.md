## 面试的本质
面试不是考试，是**一场「风险对冲」**——公司想低成本判断「你能否解决问题、是否好合作」。你的目标：用**证据**（项目/代码/推导）降低对方的疑虑，同时**判断这家公司值不值得去**。

> 记住：面试是双向选择。你也在面试公司。
