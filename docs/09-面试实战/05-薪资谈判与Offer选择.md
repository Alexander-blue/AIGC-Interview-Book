# 💵 05 · 薪资谈判与 Offer 选择

> 技术帮你拿到 offer，谈薪帮你「兑现价值」。本篇讲策略与避坑（数据为社区整理，存在个体差异，仅供参考）。

---

## 一、薪资结构（先搞懂再谈）
- **Base（月薪）**：谈薪主战场
- **绩效/奖金**：通常 2-6 个月，看评级
- **股票/期权（RSU/Option）**：分 4 年归属，大厂/独角兽占比高
- **签字费（Sign-on）**：一次性，可谈
- **补贴**：餐补/房补/加班费（注意是否含在 base 里）

> 总包 = Base×12 + 奖金 + 股票年均 + 签字费。比较 offer 看**年总包**而非月薪。

## 二、谈薪策略
1. **先让对方出价**：别先报底价。「您这边预算范围是多少？」
2. **给区间而非死数**：基于市场 + 自身水平给合理区间
3. **用其他 offer 杠杆**：礼貌告知有竞争 offer（真实），促匹配
4. **争取签字费/股票**：base 卡死时可谈 sign-on 或 RSU
5. **书面确认**：口头不算，要书面 offer 明细

## 三、Offer 对比维度（不只看钱）
| 维度 | 为什么重要 |
|------|-----------|
| 总包与成长性 | 当下收入 + 未来涨幅 |
| 业务前景 | 部门是否会裁/战略优先级 |
| 技术成长 | 能否学到跨周期能力 |
| 团队与上级 | 直接决定幸福感与成长 |
| 工作强度 | 长期可持续性 |
| 城市/生活 | 成本、家庭 |

> 原则：**第一份/早期更看重「成长与平台」，中期更看重「总包与稳定」**。别只看月薪。

## 四、避坑
- 别在 HR 面过早暴露底线薪资
- 警惕「画饼」：口头承诺的股票/晋升不算数，看书面
- 注意期权 vs RSU（期权可能归零，RSU 更稳）
- 别因一个 offer 就停止面试，多拿几个才有议价权
- 离职原因别抱怨前公司，讲「发展/方向」客观原因

## 五、高频追问
**Q：期望薪资怎么说？**
> 先问对方预算；若必须说，给「基于市场与能力的合理区间」，并强调看整体 package 与发展。避免报死数卡死自己。

**Q：两个 offer 一个钱多一个成长好怎么选？**
> 看阶段：早期选成长平台（能力复利）；若已有积累且需变现，选总包。再综合业务前景、团队、城市。没有标准答案，列维度打分。
