# ⌨️ 03 · 高频手撕代码题

> 算法/工程岗都躲不开。本篇列最常考 + 思路，配合 LeetCode 练习。重点不是背答案，是**写对 + 讲清复杂度**。

---

## 一、数据结构与算法（通用）
1. **两数之和 / 三数之和**：哈希 / 双指针，O(n) / O(n²)
2. **反转链表 / 快慢指针**：环检测、中点
3. **二叉树遍历**：前中后序（递归+迭代）、层序（队列）
4. **Top-K 问题**：堆（O(n log k)）、快选（O(n) 期望）
5. **LRU 缓存**：哈希 + 双向链表
6. **最长子串/子序列**：滑动窗口、DP
7. **岛屿数量 / 连通块**：DFS/BFS、并查集

## 二、AI 算法岗特化（常让现场实现）
1. **实现 Scaled Dot-Product Attention**：QK^T / √d → softmax → ×V；注意 mask 与数值稳定
2. **实现 RoPE 旋转**：对 (x2i, x2i+1) 做 2D 旋转
3. **实现 LoRA 前向**：Wx + (BA)x，低秩增量
4. **Softmax（数值稳定）**：减最大值防溢出
5. **交叉熵损失 + 反向**：推导并实现
6. **简单 K-Means / KNN**：距离计算、迭代
7. **Top-p / Top-k 采样**：按概率截断采样
8. **RAG 检索 Top-k**：向量相似度排序取前 k（可用堆）

## 三、系统设计（开发/平台岗）
1. **设计一个 LLM 对话 API（含流式）**：网关→模型→SSE 转发、限流、缓存、降级
2. **设计一个 RAG 系统**：ETL→切片→嵌入→检索→重排→生成，讲吞吐/一致性/成本
3. **设计一个短链/高并发计数服务**：分片、缓存、一致性
4. **设计限流**：令牌桶/漏桶

## 四、答题套路（保分）
1. **澄清**：输入规模、边界、是否允许额外空间
2. **说思路**：暴力 → 优化，讲复杂度
3. **写代码**：清晰命名、注释关键点
4. **测边界**：空输入、极值、重复
5. **分析**：时间/空间复杂度，可优化点

## 五、高频追问
**Q：手撕 Attention 要注意什么？**
> 数值稳定（softmax 减 max）、mask（padding/因果）、维度对齐（QK 同维）、√d 缩放、与 V 的乘积累加。能写对并解释即过关。

**Q：为什么考 LRU？**
> 经典「哈希+链表」组合，考察数据结构熟练度与边界处理，也是模型 KV Cache 常用的淘汰策略原型。
