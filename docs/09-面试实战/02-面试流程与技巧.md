# 🧭 02 · 面试流程与技巧

> 知己知彼。AI 岗典型流程：简历筛 → 笔试/机考 → 技术面（2-4 轮）→ 主管/交叉面 → HR 面。本篇逐轮拆解。

---

## 一、各轮应对策略

### 1. 笔试 / 机考（算法为主）
- 常考：数据结构与算法（LeetCode 中等为主）、少量 ML 概念
- 准备：刷 `04-刷题指南` + 本篇 `03-手撕代码题`
- 注意：边界条件、复杂度分析、沟通思路

### 2. 技术一面（基础 + 项目）
- 深挖简历项目（STAR 追问），基础概念（Transformer/Attention/RAG/Agent）
- 策略：用「第一性原理」回答，主动画结构、写公式
- 不会的：诚实 + 说思路，别硬编

### 3. 技术二三面（深度 + 设计）
- 算法岗：推导（LoRA/RLHF）、手撕、系统设计
- 开发岗：系统设计（高并发 AI 服务）、分布式
- 策略：展现「本质判断」与「权衡意识」

### 4. 主管 / 交叉面（广度 + 软素质）
- 问「你怎么看 X 技术/行业」「遇到冲突怎么处理」
- 策略：用 `00-导论` 的判断框架，展现思考深度与成熟

### 5. HR 面
- 聊薪资预期、职业规划、离职原因、到岗时间
- 策略：薪资留区间、展现稳定性与意愿（详见 `05-薪资`）

## 二、通用技巧
- **先澄清再答**：确认问题边界，避免答偏
- **结构化表达**：结论先行 + 分点展开（金字塔原理）
- **用图/公式辅助**：复杂概念画出来
- **主动引导**：把话题引向你擅长的项目/知识点
- **展现学习力**：被问住时展示「如何查、如何学」

## 三、反问面试官（加分区）
- 「这个岗位当前最大的技术挑战是什么？」
- 「团队的技术栈和迭代节奏？」
- 「这个职位预期 6 个月要达成什么？」
- 避免一上来只问薪资/加班

## 四、高频追问（模拟）
**Q：遇到不会的问题怎么办？**
> 先承认不熟悉，再给「我会怎么分析/查资料去解决」的思路，展现方法论与诚实。硬编比不会更扣分。

**Q：怎么体现「本质判断」？**
> 答任何技术都补一句「它的代价/局限/适用边界」，并说明「在什么场景我会选别的」。这区别于背题者。
