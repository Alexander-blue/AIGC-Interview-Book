# 🎨 01 · 前端（AI 交互层）

> AI 产品的「脸面」。Chat UI、流式输出、多模态输入是 AI 前端特有能力。

---

## 一、核心考点
- **框架**：React / Vue（组件化、状态管理 Redux/Pinia）。
- **工程**：TypeScript、构建（Vite/Webpack）、性能优化、可访问性。
- **网络**：fetch、WebSocket、SSE（流式）、拦截器。
- **状态与渲染**：虚拟列表（长对话）、Diff 算法。

## 二、AI 专属能力
- **流式渲染**：用 SSE/WebSocket 接收 LLM token 并逐字渲染（打字机效果），保留可中断/取消。
- **Chat UI**：消息流、Markdown 渲染、代码高亮、思维链展示、工具调用可视化。
- **多模态输入**：上传图片/文件 → 切片/预览 → 传给后端。
- **错误处理与降级**：请求失败、超时、模型不可用时的友好提示与重试。
- **Prompt 输入优化**：输入框、模板、历史管理。

## 三、高频追问
**Q1：SSE 和 WebSocket 怎么选做 AI 流式？**
> SSE 单向（服务端→客户端）更简单、基于 HTTP、自动重连，适合 LLM 流式输出；WebSocket 双向、适合需要客户端实时发指令/多轮交互的场景。

**Q2：长对话前端怎么不卡？**
> 虚拟列表只渲染可视区、分片加载、消息分组；超长历史可折叠/摘要；避免每次全量重渲染。
