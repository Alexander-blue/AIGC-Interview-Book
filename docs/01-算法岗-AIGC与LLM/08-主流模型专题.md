# 🤖 08 · 主流模型专题（本质对比）

> 框架会过时，**架构思想**才会留存。本篇不背参数，而是对比各家「设计取舍」——这才是面试加分点。

---

## 一、GPT 系（Decoder-only 自回归鼻祖）

- 纯 Decoder，CLM 预训练，堆叠层 + 掩码注意力。
- GPT-3 证明「规模即能力」；InstructGPT 确立 RLHF 三阶段范式。
- 闭源，生态强（API/工具链）。

## 二、LLaMA 系（开源标杆）

- Meta 开源，Decoder-only，RMSNorm + RoPE + SwiGLU + GQA（2 代起）。
- 数据配比与工程细节优秀，成为开源生态底座（无数衍生模型）。
- 本质：用相对小的参数 + 高质量数据 + 现代架构，达到接近闭源的效果。

## 三、Qwen（通义千问，阿里）

- 全尺寸覆盖（0.5B→72B+，含 MoE 版 Qwen-Max/MoE）。
- 中文与多语言能力突出，工具调用/Agent 支持好，开源友好。
- 配套生态完整（微调、部署、Agent 框架）。

## 四、DeepSeek（深度求索）

- **DeepSeek-V 系**：极致性价比，MoE 架构，长上下文。
- **DeepSeek-R1**：用 GRPO + 可验证奖励（RLVR）做推理训练，激发长链思维（CoT），开创「推理模型」开源路线。
- 本质贡献：证明「强化学习 + 可验证奖励」能显著提升推理能力，且成本极低。

## 五、Claude（Anthropic）

- 强调「Constitutional AI」（宪法式对齐），安全与长文本能力强。
- 闭源，偏企业/长文档/代码场景。

---

## 六、横向对比（面试常问「怎么选模型」）

| 维度 | 开源(LlaMA/Qwen/DeepSeek) | 闭源(GPT/Claude) |
|------|---------------------------|-------------------|
| 可控性 | 可微调/私有部署 | 仅 API |
| 成本 | 自托管可压低 | 按 token 计费 |
| 数据隐私 | 可完全本地 | 数据出域 |
| 能力上限 | 追平中大型 | 通常领先 |
| 迭代速度 | 社区快 | 厂商快 |

**选型本质**：数据敏感/成本敏感/需定制 → 开源自部署；追求最强能力/快速接入 → 闭源 API；生产常「闭源主力 + 开源兜底」混合。

---

## 七、高频追问

**Q1：Decoder-only 为什么成为 LLM 主流而非 Enc-Dec？**
> 自回归生成天然契合 Decoder-only；统一预训练目标简单；规模化经验最丰富；Encoder 的双向理解可由指令微调补偿。

**Q2：DeepSeek-R1 的「推理能力」来自哪？**
> 主要来自 GRPO 强化学习 + 可验证奖励（数学/代码对错），让模型学会「先想再做」的长链推理，而非仅靠 SFT 模仿。

**Q3：怎么给业务选模型？**
> 看：数据隐私、成本预算、延迟要求、是否需要微调、能力下限是否满足。没有万能模型，先定约束再选。
