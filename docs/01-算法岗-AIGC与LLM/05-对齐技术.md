# 🎯 05 · 对齐技术（Alignment）：SFT · RLHF · DPO · GRPO

> 对齐 = 让模型「有用、诚实、无害」。这是 2023 后大模型差异化的核心，面试高频且易深挖。

---

## 一、对齐的整体流程

```
基座模型 → SFT（监督微调，学会格式/能力）→ 奖励建模（RM）→ RL 优化（RLHF/DPO）
```

- **SFT**：用高质量「指令-回答」教模型会做事。
- **RM（Reward Model）**：学「人类偏好」的打分函数。
- **RL**：用 RM 做信号，强化模型生成「高分回答」。

---

## 二、RLHF 三阶段（经典）

### 阶段1：SFT（Supervised Fine-Tuning）
用标注数据微调，得到初始策略 $\pi_{SFT}$。

### 阶段2：训练奖励模型 RM
收集「同一 prompt 的多个回答 + 人类排序」，训一个打分模型 $r_\theta(x,y)$。损失用 Bradley-Terry 偏好模型：

$$\mathcal{L}_{RM} = -\mathbb{E}_{(x,y_w,y_l)}\left[\log \sigma(r_\theta(x,y_w) - r_\theta(x,y_l))\right]$$

$y_w$ 胜出回答，$y_l$ 落败回答。

### 阶段3：PPO 强化学习
用 RM 作为奖励，PPO 优化策略，同时加 **KL 惩罚**防止偏离 SFT 太远：

$$\max_\pi \mathbb{E}_{x\sim D, y\sim\pi}\left[r_\theta(x,y) - \beta\, \text{KL}(\pi(\cdot|x)\,\|\,\pi_{ref}(\cdot|x))\right]$$

**为什么加 KL？** 防止模型为了刷 RM 高分而「欺骗奖励」（reward hacking），保持语言自然。

---

## 三、DPO（Direct Preference Optimization）⭐

**思想**：不需要显式 RM 和 RL，直接用一个分类损失在偏好数据上优化策略。

$$\mathcal{L}_{DPO} = -\mathbb{E}\left[\log \sigma\left(\beta \log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)\right]$$

**DPO 的优势**：
- 省去训 RM + 跑 RL 的复杂流程，训练更稳定
- 只需偏好对，实现简单（一个交叉熵式损失）
- 工业界大量采用

**DPO vs PPO**：
| | PPO/RLHF | DPO |
|---|---|---|
| 是否需要 RM | 是 | 否（隐式） |
| 是否需要 RL 循环 | 是 | 否 |
| 稳定性 | 较难 | 较易 |
| 效果上限 | 通常更高（可在线迭代） | 接近，且更省 |

---

## 四、GRPO（Group Relative Policy Optimization）

**用于推理模型（如 DeepSeek-R1）**。省去独立 critic/value 网络：对同一 prompt 采样一组回答，用**组内相对得分**做基线。

- 优势：省显存（无 value 网络）、适合数学/代码等可验证奖励
- 常与「可验证奖励 RL（RLVR）」结合：用单元测试/答案对错当奖励，而非训练 RM

---

## 五、对齐的核心难题

1. **Reward Hacking**：模型钻 RM 空子（如冗长、拍马）。需 RM 迭代 + 在线人类反馈。
2. **分布偏移**：RM 只在有限数据上训，策略偏移后 RM 不再准。
3. **偏好数据质量**：标注一致性差会严重拖累。
4. **过度对齐（Over-alignment）**：过度安全/谄媚，反而能力下降。

---

## 六、高频追问

**Q1：为什么需要 KL 惩罚？**
> 防止策略为刷奖励而生成不自然/偏离分布的文本，保持语言流畅与多样性。

**Q2：DPO 为什么能不用 RM？**
> DPR 把「RM 打分 + KL 约束」的最优解写成闭式，直接转化为策略间的偏好比损失，等效于隐式对齐。

**Q3：PPO 和 DPO 怎么选？**
> 追求极致且能跑 RL 管线 → PPO（尤其在线迭代）；追求简单稳定 → DPO。R1 类推理模型常用 GRPO/RLVR。

**Q4：什么是 RLHF 的 reward hacking？怎么缓解？**
> 模型利用 RM 漏洞得高分但质量差。缓解：RM 持续用新数据更新、加 KL、多维度奖励、人工抽检。
