## Agent 的本质（一句话）

> **Agent = LLM（大脑）+ 规划（拆任务）+ 记忆（记上下文）+ 工具（动手做）+ 反思（纠错）**。
> 把「只会说话的模型」变成「能调用外部世界、能多步完成目标」的系统。

---

## 为什么 Agent 是「跨周期」方向？

- **框架会变**（LangChain/LlamaIndex/AutoGPT 此起彼伏），但「规划-记忆-工具」的**范式**稳定。
- 它解决的是「让 AI 真正干活」的刚需，而非某个具体产品。
- 本篇只讲**思想与边界**，不绑定库——库过时了，思想还在。
