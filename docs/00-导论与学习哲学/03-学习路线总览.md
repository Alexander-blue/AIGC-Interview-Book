# 🧭 03 · 学习路线总览

> 不同背景、不同目标的人，学习路径差异巨大。本章给你 4 条可执行的路线 + 时间预估 + 里程碑自检。

---

## 路线 A：零基础转行 AI 应用开发（最稳妥、岗位最多）

**目标**：6-9 个月，达到 AI 应用开发/算法应用工程师水平，能独立做 RAG/Agent 项目。

| 阶段 | 时间 | 内容 | 里程碑（能做什么） |
|------|------|------|---------------------|
| A1 基础 | 1-2 月 | Python 扎实、线性代数/概率入门、Git/Linux | 写脚本、调 API |
| A2 LLM 入门 | 1-2 月 | `01-LLM` 基础篇、Prompt 工程、API 调用 | 搭一个问答机器人 |
| A3 RAG/Agent | 2 月 | `03-AI Agent`、`08-AI应用开发` | 做带检索+工具的 Agent |
| A4 工程化 | 1-2 月 | 向量库、推理部署、LLMOps、`09-面试` | 上线一个可演示项目 |
| A5 求职 | 持续 | 简历、真题、模拟面试 | 拿到 offer |

➡️ 重点看：`06-开发岗` → `08-AI应用开发` → `03-AI Agent`

---

## 路线 B：科班研究生冲算法岗（深度优先）

**目标**：吃透模型原理与推导，能答「深问 + 手撕」。

| 阶段 | 内容 | 里程碑 |
|------|------|--------|
| B1 根基 | `04-传统深度学习` 全、数学 | 推导 BP、CNN、RNN |
| B2 大模型 | `01-LLM` 全（Transformer 推导、注意力、位置编码、RLHF/DPO 推导） | 手写 MHA/RoPE/LoRA |
| B3 生成+Agent | `02-生成式`、`03-AI Agent` | 理解 Diffusion 与 Agent 范式 |
| B4 前沿 | `05-前沿与具身`、顶会论文 | 能讲清一个前沿方向 |
| B5 实战 | 复现论文 / Kaggle / 实习 | 有产出证明深度 |

➡️ 重点看：`01-LLM` → `04-传统深度学习` → `算法岗真题`

---

## 路线 C：后端/前端工程师转 AI（工程杠杆）

**目标**：用现有工程能力 + AI 应用知识，切入高薪 AI 应用岗。

- 不必重学数学，直接 `08-AI应用开发` + `03-AI Agent`
- 用你的语言优势（Java/Go/前端）做 AI 平台/中间件，差异化竞争
- 补 `01-LLM` 的「原理够用层」即可（不必推导，但要知道为什么）

➡️ 重点看：`07-开发岗` → `08-AI应用开发` → `开发岗真题`

---

## 路线 D：在职，做长期职业规划（战略视角）

- 先读 `00-导论`（本质判断）+ `10-职业发展与资源`
- 用「跨周期技术地图」盘点自己的技能，补齐 L0/L1 短板
- 每季度定向补一个 L2 技术，保持对 L4 的嗅觉
- 结合 `10-薪资爆料/公司指南` 做 1-3 年职业决策

## 自我检测的「过关清单」

**LLM 算法岗最低过关线**（能流畅讲清 + 推导）：
- [ ] Transformer 结构、自注意力公式与复杂度
- [ ] 位置编码（绝对/相对/RoPE）思想与差异
- [ ] 预训练目标（MLM/CLM）、Scaling Law 直觉
- [ ] 微调：LoRA 原理、与全参微调的代价对比
- [ ] 对齐：RLHF 三阶段、PPO vs DPO 区别
- [ ] 解码：贪心/采样/温度/top-p、KV Cache
- [ ] 推理优化：量化、KV Cache、投机解码、MoE

**AI 应用开发最低过关线**：
- [ ] 能独立搭一个 RAG（分块/嵌入/检索/重排/生成）
- [ ] 能设计一个 Agent（ReAct、工具、记忆）
- [ ] 会选型和用向量库、了解 LLMOps 基础
- [ ] 能做成本/延迟/质量的权衡

---

## 时间管理建议

- **每日 2 小时 > 周末 14 小时**：AI 知识密度高，靠持续而非突击。
- **70/20/10 法则**：70% 时间学核心（L0/L1/L2），20% 动手项目，10% 看前沿。
- **产出驱动**：每学一个模块，写一篇笔记或一个 demo，发到 GitHub/博客。
