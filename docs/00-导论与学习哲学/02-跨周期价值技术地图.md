# 🗺️ 02 · 跨周期价值技术地图

> 一张图告诉你：哪些技术值得你用「年」为单位投入，哪些只是「月」级热点。
> 本图会随技术演进更新，但**范式层（绿色）几乎不会变**。

---

## 一、技术分层模型（从最稳定到最易变）

```
┌─────────────────────────────────────────────────────────────┐
│ L0 数学与系统基础（10年+ 不变，是一切的底座）                  │
│   线性代数 · 概率统计 · 优化理论 · 信息论 · 分布式系统 · 软件工程 │
├─────────────────────────────────────────────────────────────┤
│ L1 AI 核心范式（5年+ 跨周期，建议学透）                        │
│   注意力机制 · 反向传播 · 预训练+微调 · 对齐(RLHF/DPO) ·         │
│   生成模型范式(Diffusion/AR) · RAG · Agent(规划/记忆/工具)      │
├─────────────────────────────────────────────────────────────┤
│ L2 主流架构与训练方法（2-4年，持续演进）                       │
│   Transformer变体 · MoE · 长上下文 · LoRA/QLoRA · 量化推理 ·    │
│   多模态对齐 · 强化学习(PPO/GRPO)                              │
├─────────────────────────────────────────────────────────────┤
│ L3 具体模型/框架/工具（6-18个月，易过时）                      │
│   具体LLM(某版本) · LangChain/LlamaIndex · 某推理引擎 ·         │
│   某Agent框架 · 某向量库版本                                   │
├─────────────────────────────────────────────────────────────┤
│ L4 前沿观察区（不确定性高，跟踪不深投）                        │
│   世界模型 · 具身智能落地 · AGI路线 · 神经架构搜索新范式 ·       │
│   某篇刚出的SOTA论文                                           │
└─────────────────────────────────────────────────────────────┘
```

**学习策略**：L0/L1 投入 60% 时间并反复夯实；L2 投入 30%；L3 用到再学；L4 保持阅读、不盲投。

---

## 二、跨周期技术清单（🟢 建议学透）

| 技术 | 跨周期理由 | 投入建议 |
|------|------------|----------|
| **注意力机制 / Transformer** | 已成序列建模事实标准，10 年内难被替代 | 学透原理+推导+复杂度 |
| **预训练 + 微调范式** | 数据驱动的表示学习范式稳固 | 理解 Scaling Law、数据、算力三角 |
| **对齐（RLHF / DPO / 指令微调）** | 「让模型符合人类意图」是长期需求 | 理解目标函数差异与权衡 |
| **生成模型范式（Diffusion / 自回归）** | 两大范式各有适用，思想跨场景 | 理解两者本质差异与取舍 |
| **RAG（检索增强）** | 解决「知识时效性/可溯源」的刚需 | 学透分块/检索/重排/评估 |
| **Agent 范式（规划/记忆/工具）** | 比具体框架更持久的能力抽象 | 学范式而非某个库 |
| **分布式训练 / 推理优化** | 算力约束长期存在 | 工程岗必学，算法岗建议了解 |
| **评估方法论** | 「不可评估则不可改进」永远成立 | 学指标设计、基准、人工评估 |

## 三、稳健工程层（🟡 重点学应用）

- 向量数据库（Milvus / pgvector / FAISS）的使用与选型
- 推理加速（vLLM / TensorRT-LLM / Ollama）的部署与调优
- 模型量化（INT8/INT4/AWQ/GPTQ）的精度-速度权衡
- LLMOps：可观测、成本、缓存、降级、评测闭环
- 提示工程（CoT / Few-shot / 结构化输出）的系统性方法

---

## 四、前沿观察区（🔵 跟踪不深投）

> 这些方向**重要但结论未定**，建议养成「定期阅读顶会/技术博客」的习惯，而非一次性深度学习。

- **世界模型（World Model）**：JEPA、Dreamer 路线能否统一感知-预测-控制？
- **具身智能（Embodied AI）**：Sim2Real、机器人基础模型的进展
- **AGI 路线之争**：尺度定律是否会平缓？推理时计算（test-time compute）是不是新范式？
- **Agentic RL**：用强化学习训 Agent 的长期记忆与工具使用
- **神经架构新探索**：State Space Model（Mamba）、线性注意力能否替代 softmax 注意力？

---

## 五、谨慎对待区（🔴 了解即可）

- 把旧技术换皮成「AI + X」但无本质改进的伪创新
- 仅靠单篇论文、无复现无落地、benchmark 存疑的「SOTA」
- 过度承诺「取代程序员/取代算法工程师」的营销叙事

---

## 六、如何使用这张地图

1. 学任何新技术前，先把它「贴」到上面的某一层。
2. 贴到 L0/L1 →  slowdown，学透；贴到 L3 → 快速上手即可。
3. 定期（每季度）回看 L4，把其中「升格」到 L2 的技术补学。
4. 把你的学习产出（项目/笔记）沉淀到 `面试真题集` 与自己的知识库。

> 💡 跨周期能力 = **L0/L1 的扎实底座 + 对 L4 的敏锐嗅觉 + 不被 L3 牵着走的自制力。**
