## 为什么需要「学习哲学」？

过去十年，AI 领域出现了多次「范式切换」：

- 2012 年 AlexNet 引爆深度学习 → 2017 年 Transformer 统一序列建模 →
- 2018-2020 年 BERT/GPT 预训练范式 → 2022 年 ChatGPT 引爆大模型 →
- 2023-2024 年 多模态 / Agent / RAG 爆发 → 2025+ 年 推理模型 / Agentic RL / 世界模型。

**每一轮切换，都会让上一轮「背得最熟的人」部分过时。** 如果你只会背当前热点，你永远在追尾巴。

所以本项目反其道而行：**教你在任何一轮技术浪潮中，都能快速判断「这个技术值不值得投入、投入多久、学到什么深度」。** 这套判断力，比任何单一知识点都保值。

## 三条元原则（贯穿全书）

1. **第一性原则（First Principles）**
   任何技术都问：它**到底在优化什么目标函数/解决什么瓶颈**？一旦你能用一句话说清它的「问题-方案-代价」，你就真的懂了，也忘不掉。

2. **可迁移优先（Transferable First）**
   优先学**十年后还在用**的东西：数学基础、概率论、优化理论、分布式系统、软件工程、系统设计、对「误差与不确定性」的直觉。这些是换任何技术栈都不作废的资产。

3. **产出导向（Output-Oriented）**
   学一个技术，立刻用它做点东西（代码/项目/文章）。**没有产出的学习，90% 会忘。** 本项目每个模块都配套「动手清单」。

## 给不同读者的开场白

- **如果你是学生/转行小白**：别焦虑。AI 行业最稀缺的不是「什么都会的人」，而是「能把一件事做扎实的人」。从 `03-学习路线` 找到你的起点。
- **如果你是科班研究生冲算法岗**：你的护城河是**深度**。把 `01-LLM` 和 `04-传统深度学习` 的推导啃透，比刷 100 道浅题有用。
- **如果你是工程师转 AI 应用开发**：你的机会在「落地」。算法岗卷不过博士，但能把模型变成稳定、低成本、可监控产品的工程师极稀缺。重点看 `08-AI应用开发`。
- **如果你已工作想规划长期路线**：直接看 `10-职业发展与资源`。
