# ⚙️ 03 · C / C++（推理引擎与高性能）

> 大模型的「底层命脉」：推理引擎（TensorRT/vLLM 内核）、算子优化、嵌入式端侧都靠 C/C++。算法岗做训练框架、开发岗做高性能服务都受益。

---

## 一、核心考点
- **内存管理**：栈/堆、指针、野指针、内存泄漏（valgrind/ASan）。
- **RAII（C++）**：用对象生命周期管理资源，异常安全。
- **智能指针**：unique_ptr / shared_ptr / weak_ptr。
- **引用 vs 指针**、移动语义（std::move）、拷贝消除。
- **并发**：std::thread、原子操作、锁、无锁结构。
- **虚函数/多态**、对象模型、虚表。

## 二、AI 结合点
- **推理引擎开发**：TensorRT、ONNX Runtime、vLLM 的 CUDA kernel。
- **算子优化**：算子融合、量化 kernel、FlashAttention 实现。
- **高性能服务**：用 C++ 写低延迟推理网关/批处理。
- **端侧部署**：手机/NPU 上的模型推理（NCNN/MNN）。

## 三、面试侧重
- 算法岗：常考「手撕」数据结构/算法（见 `09-面试实战/高频手撕代码题`），C++ 实现。
- 开发岗：考内存安全、并发、性能优化意识。

## 四、高频追问
**Q1：shared_ptr 有什么坑？**
> 循环引用导致内存泄漏（用 weak_ptr 打破）；引用计数有原子开销；大对象传递建议用移动而非拷贝。

**Q2：C++ 怎么避免内存泄漏？**
> 优先 RAII + 智能指针；明确所有权；用 ASan/valgrind 检测；资源获取即初始化。

**Q3：为什么推理引擎多用 C++？**
> 对硬件（GPU/NPU）控制和性能极致优化能力最强，零成本抽象，适合低延迟、高吞吐的推理与算子实现。
