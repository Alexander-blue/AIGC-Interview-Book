# 🔌 05 · 嵌入式与端侧 AI（AIoT / Edge AI）

> 把 AI 放到设备端：手机、车载、IoT、机器人。端侧推理是「隐私 + 低延迟 + 离线」的关键方向。

---

## 一、核心考点
- **MCU/RTOS**：单片机（STM32 等）、实时操作系统（FreeRTOS）、中断/定时器。
- **交叉编译**：在 PC 编译、在 ARM/嵌入式设备运行。
- **内存与算力限制**：KB~MB 级内存、无 MMU、低功耗约束。
- **外设与总线**：I2C/SPI/UART、传感器采集。
- **C/C++ 主导**，部分用 Rust（安全）、MicroPython（原型）。

## 二、端侧 AI 结合点
- **模型压缩**：量化（INT8/INT4）、剪枝、蒸馏，使模型适配端侧。
- **端侧推理框架**：NCNN、MNN、TFLite、TensorRT-LLM（边缘 GPU）、ONNX Runtime Mobile。
- **NPU/专用加速**：利用芯片 AI 加速器（如手机 NPU、地平线/昇腾）。
- **应用场景**：语音唤醒、人脸识别、手势、车载感知、工业质检。

## 三、高频追问
**Q1：端侧部署为什么必须量化？**
> 端侧算力/内存/功耗有限，FP32 模型跑不动；INT8/INT4 量化大幅降资源且精度损失可控，是端侧落地关键。

**Q2：端侧和云端推理怎么分工？**
> 云端：大模型、复杂任务；端侧：低延迟/隐私/离线的小模型（唤醒词、简单识别）。常「端侧预处理 + 云端重推理」混合。

**Q3：嵌入式实时性如何保证？**
> 用 RTOS 保证确定时延、优先级调度、中断响应；避免在关键路径做重计算；用 DMA 等硬件卸载。
