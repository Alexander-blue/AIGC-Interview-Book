## 开发岗的「AI 差异化」

普通 CRUD 工程师很多，**既懂工程又懂 AI 的工程师极少**。在 AI 公司，开发岗常要：

- 把 LLM/Agent/RAG 集成进业务系统（API、流式、缓存、降级）
- 写推理服务、向量检索、Prompt 管理后台
- 做 AI 平台（数据标注、评测、监控）
- 端侧把模型部署到手机/嵌入式

→ 建议配合 `08-AI应用开发` 一起看，竞争力翻倍。
