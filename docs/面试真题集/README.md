## 使用建议
1. **第一轮**：遮住答案，口头/书面作答，计时（每题 2-3 分钟）
2. **第二轮**：对照要点，标红不会的
3. **第三轮**：回 `docs/` 对应章节，把薄弱模块吃透
4. **冲刺**：用 `09-面试实战` 的 STAR 稿 + 手撕题做模拟面试

> 真题会随技术演进更新，但**考点范式稳定**。真正该练的是「用第一性原理组织答案」的能力。
