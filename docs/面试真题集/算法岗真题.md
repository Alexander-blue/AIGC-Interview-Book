# 🧮 算法岗真题（30+）

> 考点：Transformer / LLM / 微调 / 对齐 / 生成 / 传统 DL / 推导。每题给**要点**（踩分点），不是背诵稿。

---

## 一、Transformer 与注意力（基础必考）
**1. 自注意力公式与复杂度？**
> $Attention=softmax(QK^T/√d_k)V$；复杂度 $O(n^2d)$。$n$ 是瓶颈 → 长上下文优化根源。

**2. 为什么缩放因子是 $√d_k$？**
> 防点积方差过大使 softmax 饱和、梯度小。除以 $√d_k$ 使方差≈1。

**3. Multi-Head 为什么有效？**
> 不同头在不同子空间关注不同关系（语法/语义/指代），表达力强于单一注意力。

**4. Encoder 和 Decoder 区别？**
> Encoder 双向（理解，如 BERT）；Decoder 带因果掩码（生成，如 GPT）。

**5. 为什么用残差 + LayerNorm？**
> 残差缓解深层梯度消失；Pre-LN 训练更稳，是大模型默认。

## 二、位置编码
**6. 为什么需要位置编码？**
> 自注意力排列不变，需注入顺序信息（"我打你"≠"你打我"）。

**7. RoPE 的核心性质？**
> 旋转 Query/Key，使内积只依赖相对位置 $m-n$，利于长度外推。

**8. 绝对 vs 相对位置编码？**
> 绝对（可学习/正弦）外推差；相对更贴语言结构、外推好（T5/RoPE）。

## 三、预训练与 Scaling
**9. CLM 和 MLM 区别？为何大模型多用 CLM？**
> CLM 自回归预测下一 token，统一生成；MLM 有 [MASK] 不一致。CLM 天然支持生成。

**10. Scaling Law 是什么？Chinchilla 结论？**
> 损失随参/数/算力幂律下降；Chinchilla 指出约 20 tokens/参数最优配比。

## 四、微调
**11. LoRA 原理与参数量计算？**
> $\Delta W=BA$（低秩），参数量从 $d×k$ 降到 $r(d+k)$；例 d=k=4096,r=8 → 缩减~256倍。

**12. LoRA vs 全参微调？**
> LoRA 省资源/防遗忘/多任务；全参上限高但贵。多数工业场景 LoRA 够。

**13. QLoRA 怎么单卡训大模型？**
> 4-bit NF4 量化主干 + 分页优化器 + LoRA 只训少量参数。

## 五、对齐
**14. RLHF 三阶段？**
> SFT → 训奖励模型 RM（偏好排序）→ PPO 强化（带 KL 惩罚）。

**15. PPO 为什么加 KL 惩罚？**
> 防策略为刷 RM 而 reward hacking，保持语言自然。

**16. DPO 相比 PPO 好在哪？**
> 不需显式 RM 和 RL 循环，直接偏好损失，更稳更简单。

**17. GRPO 是什么？用在哪？**
> 组相对策略优化，省 value 网络；用于推理模型（R1）配可验证奖励 RLVR。

## 六、推理优化
**18. KV Cache 是什么、占多少显存？**
> 缓存历史 K,V 避免重算；显存随序列长线性增长，是长上下文瓶颈。

**19. GQA 相比 MQA 好在哪？**
> MQA 共享过头损质量；GQA 分组共享，质量/速度更平衡（LLaMA2+ 默认）。

**20. 量化会损精度为什么还能用？**
> 大模型有冗余；AWQ/GPTQ 保护重要通道，W4 下任务损失常 <1%。

**21. 投机解码为什么能加速且不损分布？**
> 小模型草拟+大模型一次并行验证，命中率高则加速；输出分布与大模型一致（无损）。

## 七、MoE 与长上下文
**22. MoE 为什么「大参数低推理成本」？**
> 参数分布多专家，路由只激活少数，单 token 算力≈激活专家数，但显存要装全部。

**23. 为什么需要负载均衡损失？**
> 防路由偏好少数专家导致坍缩，均衡 token 分配。

**24. 长上下文外推怎么做？**
> NTK-aware RoPE / 位置插值，把训练位置频率缩放映射回已训练范围。

## 八、生成模型
**25. Diffusion 前向/反向过程？**
> 前向逐步加噪（固定），反向训网络预测噪声逐步去噪。损失 $\|ε-ε_θ\|²$。

**26. CFG 是什么、w 太大问题？**
> 无分类器引导，放大条件信号；$w$ 太大过饱和、多样性降。

**27. Diffusion vs GAN？**
> Diffusion 训练稳质量高但慢；GAN 快但训练不稳易 collapse。

**28. VAE 的 KL 项作用？**
> 约束隐空间接近先验，保证能从随机 z 采样生成。

## 九、传统 DL
**29. 推导/解释反向传播？**
> 链式法则从损失逐层求偏导更新参数；是深度学习的优化基础。

**30. ResNet 残差为什么有效？**
> 梯度直连缓解退化，学残差比学映射易，可训更深。

**31. BatchNorm vs LayerNorm？**
> BN 跨 batch 同通道（CV）；LN 对单样本整层（NLP，长度不一友好）。

## 十、RL
**32. 策略梯度 vs Q-learning？**
> PG 直接优化策略（连续友好）；Q-learning 学价值再贪心（离散）。Actor-Critic 结合。

**33. PPO 比普通 PG 稳的原因？**
> ratio 裁剪限制单步更新幅度，避免策略突变崩溃。
