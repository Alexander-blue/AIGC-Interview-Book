# 💻 开发岗真题（30+）

> 覆盖：Python/Java/Go/C++、前端/后端/测试/运维、AI 应用开发、系统设计。兼顾通用工程与 AI 场景。

---

## 一、Python
**1. GIL 是什么、如何真正并行？**
> 同进程同刻仅一线程执行字节码；用 multiprocessing 或多进程/C 扩展；IO 用 asyncio。

**2. asyncio 适合什么？**
> 高并发 IO（批量 LLM 请求、流式输出），CPU 密集仍受 GIL 限。

**3. 默认可变参数陷阱？**
> 默认参数在函数定义时绑定，可变对象（list）会被多次调用共享 → 用 None 默认再初始化。

**4. 深拷贝浅拷贝区别？**
> 浅拷贝共享嵌套对象引用；深拷贝递归复制全部，互不干扰。

## 二、Java
**5. HashMap 线程安全吗？**
> 不安全；并发用 ConcurrentHashMap（细粒度锁/CAS）。

**6. JVM GC 常见算法？**
> G1（可预测停顿）、ZGC（超低停顿，大堆友好）。调优看 OOM/停顿。

**7. synchronized vs volatile？**
> volatile 保证可见性不保证原子；synchronized 保证原子+可见+有序（互斥）。

**8. Java 怎么流式输出 LLM？**
> SSE/WebSocket 实时推前端；后端响应式 client 消费上游流式并转发。

## 三、Go
**9. goroutine vs 线程？**
> goroutine 用户态调度、栈仅几 KB，单机可百万级；OS 线程重（MB 级）。

**10. Channel 关闭注意？**
> 向关闭 channel 发送 panic；多生产者谨慎关闭；for-range 自动退出。

**11. Go 适合写 LLM 推理服务吗？**
> 适合网关/编排/代理层（高并发易部署）；模型计算仍在 Python/C++ 引擎。

## 四、C/C++
**12. shared_ptr 坑？**
> 循环引用泄漏（weak_ptr 打破）；引用计数原子开销；大对象用移动。

**13. RAII 是什么？**
> 资源获取即初始化，用对象生命周期管理资源，异常安全，C++ 核心惯用法。

**14. 为什么推理引擎多用 C++？**
> 对硬件极致优化、零成本抽象，适合低延迟高吞吐推理与算子。

## 五、前端
**15. SSE vs WebSocket（AI 流式）？**
> SSE 单向服务端→客户端、简单、自动重连，适合 LLM 流式；WebSocket 双向适合实时交互。

**16. 长对话前端怎么不卡？**
> 虚拟列表、分片加载、消息分组、避免全量重渲染。

**17. AI Chat UI 关键能力？**
> 流式渲染、Markdown/代码高亮、思维链展示、工具调用可视化、错误降级。

## 六、后端 / 架构
**18. AI 后端和普通后端最大区别？**
> 多「不确定性+高延迟+高成本」：需流式、缓存、降级、成本计量、并发控制。

**19. 怎么做 LLM 调用缓存降本？**
> 语义缓存（相似问题复用）、精确缓存、热点预生成、模型路由小模型处理简单问题。

**20. RAG 多租户怎么隔离？**
> 向量库按 tenant 过滤/独立 collection、行级权限、对话归属校验防泄漏。

**21. 设计一个 LLM 对话 API（含流式）？**
> 网关（鉴权/限流/成本）→ 模型路由 → 消费上游 SSE → 转发前端；加缓存/降级/追踪。

## 七、测试 / 运维
**22. AI 输出不确定怎么写测试？**
> 不测逐字相等，测属性：评测集+自动打分（LLM-as-Judge）；关键逻辑确定性 mock。

**23. 推理服务怎么扩缩容？**
> 按并发/GPU 利用率扩 Pod；连续批处理提吞吐；监控 KV Cache 与并发。

**24. AI 运维多了什么？**
> 模型层指标：token 用量、延迟分解、幻觉率、评测分、Prompt 版本、成本告警。

**25. Prompt 改坏效果怎么防？**
> 维护评测集、CI 跑评测门禁、版本管理可回滚、灰度。

## 八、AI 应用 / 商业化
**26. 为什么很多 AI 项目失败？**
> 无真痛点、成本算不过账、可靠性不达标、数据/合规卡死、护城河低（套壳）。

**27. 套壳 API 产品风险？**
> 无护城河、毛利受 API 成本挤压、易被替代；需走数据/工作流/领域深度。

**28. 高价值 AI 落地场景？**
> 客服问答、代码助手、文档处理、营销内容、数据分析、垂直行业（法律/医疗/金融）。

**29. AI 应用架构最易漏的环节？**
> 可观测与评测闭环、降级与成本治理、安全与权限。

**30. 私有化 vs 云 API 怎么选？**
> 数据敏感/合规/规模大 → 私有化；快速验证 → 云 API 起步后迁移。
