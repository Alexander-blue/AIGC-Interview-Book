# 👁️ 02 · 计算机视觉 CV

> 从 CNN 到 ViT。即使大模型时代，CV 岗、多模态岗仍考这些。

---

## 一、CNN（卷积神经网络）
- **卷积**：局部感受野 + 权值共享 → 平移不变、参数少
- **池化**：降维、增强平移不变
- **经典结构**：LeNet → AlexNet → VGG → ResNet（残差解决退化）→ MobileNet（深度可分离，轻量）
- **1×1 卷积**：降维/升维、跨通道交互

## 二、目标检测
- **Two-stage**：R-CNN 系列（先候选框再分类），精度高速度慢
- **One-stage**：YOLO / SSD（端到端一次出框+类），速度快
- **Anchor-free**：FCOS / CenterNet（直接预测关键点）
- 指标：mAP、IoU

## 三、语义/实例分割
- 语义分割：FCN / U-Net / SegFormer（逐像素分类）
- 实例分割：Mask R-CNN
- 指标：mIoU

## 四、Transformer 进 CV（ViT）
- 把图像切成 patch，当作 token 序列，输入 Transformer
- 大数据下 ViT 超越 CNN；小数据下 CNN 仍稳
- 混合：ConvNeXt（CNN 现代化）、Swin（分层窗口注意力）

## 五、数据增强与训练技巧
- 翻转/裁剪/色彩抖动/Mixup/CutMix
- 预训练+微调、迁移学习

## 六、高频追问
**Q1：ResNet 残差为什么有效？**
> 允许梯度直连，缓解深层退化；学习「残差 F(x)=H(x)-x」比直接学映射更容易，训练更深更稳定。

**Q2：CNN 和 ViT 怎么选？**
> 数据少/实时/端侧 → CNN（ConvNeXt）；大数据追求上限/需与多模态统一 → ViT。现实多混合。

**Q3：YOLO 为什么快？**
> One-stage 端到端，单次前向直接出框与类别，无候选框生成阶段，推理高效。
