# 📊 01 · 机器学习基础

> 算法岗的地基。反向传播能推导、过拟合能讲清，是基础门槛。

---

## 一、监督学习三要素
- **模型**：假设空间（线性/树/神经网络）
- **策略**：损失函数（MSE / 交叉熵 / Hinge）
- **算法**：优化（梯度下降）

## 二、梯度下降与反向传播（⭐ 必会）
- **前向**：逐层计算输出与损失
- **反向**：链式法则从损失对每层参数求偏导
- **更新**：$w \leftarrow w - \eta \nabla_w L$
- 变体：BGD / SGD / mini-batch；优化器 SGD / Momentum / Adam（自适应学习率）

## 三、过拟合与正则
- **过拟合**：训练好、测试差。原因：数据少/模型复杂/噪声。
- **缓解**：更多数据、正则（L1/L2/Dropout）、早停、数据增强、简化模型、集成。
- **偏差-方差权衡**：高偏差→欠拟合；高方差→过拟合。

## 四、评估
- 分类：Accuracy / Precision / Recall / F1 / AUC-ROC
- 回归：MSE / MAE / R²
- 不平衡数据看 PR 曲线而非 Accuracy
- 交叉验证防过拟合估计

## 五、经典模型速览
- 线性/逻辑回归、SVM、决策树、随机森林、GBDT/XGBoost/LightGBM（表格数据王者）
- 聚类：K-Means、DBSCAN；降维：PCA、t-SNE

## 六、高频追问
**Q1：为什么用交叉熵而不是 MSE 做分类？**
> 交叉熵与最大似然一致，梯度更友好；MSE 在 sigmoid 输出下易梯度消失，且分类概率语义不符。

**Q2：Adam 一定比 SGD 好吗？**
> 不定。Adam 收敛快但泛化有时不如调好的 SGD；大模型训练多用 AdamW（解耦权重衰减）。

**Q3：Dropout 为什么有效？**
> 训练时随机丢弃神经元，等价于训练多个子网络集成，降低神经元共适应，增强泛化。
