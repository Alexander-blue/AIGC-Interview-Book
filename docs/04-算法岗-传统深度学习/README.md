## 为什么传统 DL 仍然重要？

1. **大模型建立在它之上**：Transformer 是深度学习的延续，不懂 BP 就难懂训练。
2. **很多业务不需要大模型**：推荐、搜索、风控、时序预测仍靠传统 ML/DL，岗位多。
3. **面试区分度**：能推导 BP/CNN/RNN 的人，比只会 prompt 的人更能打硬仗。
4. **跨周期**：反向传播、梯度优化、卷积、序列建模思想，十年不变。
